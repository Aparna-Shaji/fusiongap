# ADR-0001: Environment and Toolchain Pins

- Status: Proposed
- Date: 2026-11-03

## Context

This project requires a reproducible GPU development environment
for benchmarking and experimentation with PyTorch, Triton, and
TorchInductor.

The target local GPU is NVIDIA GTX 1650 (SM_75).

Final software versions will be selected after the environment
compatibility tests.

## Decision Drivers

The environment will be evaluated using these criteria:

| Criterion | Weight |
|---|---:|
| SM_75 compatibility evidence | 40 |
| Reproducibility and exact version pinning | 25 |
| Ease of learning | 20 |
| Interview relevance | 15 |
| Total | 100 |

## Candidates

Candidates will be evaluated for:

- Environment manager
- Python version
- PyTorch version
- Triton version
- CUDA toolkit
- Compiler
- Build system
- Testing tools
- Profilers
- CI system

## Decision

Final selections: TBD

The final versions and tools will be selected after the
environment tests at Stage 05.

## Consequences

- The environment must be reproducible.
- Selected versions must be documented and pinned.
- SM_75 compatibility must be supported by test evidence.
- Any changes to the selection criteria or weights must be documented.
